🔑 Google OAuth Credentials

Buat credentials agar aplikasi bisa mengakses Google Drive dan Sheets atas nama kamu.

  1. Buka Google Cloud Console
  2. Buat project baru → aktifkan Google Drive API dan Google Sheets API
  3. Menu: APIs & Services → Credentials → + Create Credentials → OAuth 2.0 Client ID
  4. Application type: Desktop app → Create
  5. Salin Client ID dan Client Secret ke bawah ini
  6. Di OAuth consent screen, tambahkan email kamu sebagai Test user

📁 Google Drive Folder

Semua gambar dari WhatsApp akan diupload ke folder Google Drive yang kamu tentukan.

  1. Buka Google Drive
  2. Buat atau buka folder tujuan
  3. Lihat URL browser: drive.google.com/drive/folders/[ID INI]
  4. Salin ID tersebut ke kolom di bawah

📊 Google Sheets

Data pesan (tanggal, keterangan, link gambar) akan otomatis dicatat ke spreadsheet ini.

  1. Buka atau buat Google Spreadsheet baru
  2. Lihat URL: docs.google.com/spreadsheets/d/[ID INI]/edit
  3. Salin ID tersebut ke kolom di bawah
  4. Pastikan ada tab sheet bernama Data (atau isi nama lain)

💬 WhatsApp Group (Opsional)

Group ID menentukan grup mana yang dipantau. Boleh dikosongkan dulu dan diisi setelah scan QR.

  1. Kosongkan dulu, klik Simpan & Mulai
  2. Scan QR Code WhatsApp yang muncul di Dashboard
  3. Kirim pesan sembarang ke grup target
  4. Lihat tab Monitor → Live Logs — Group ID akan muncul di sana
  5. Salin Group ID, lalu buka tab Pengaturan dan tempel ID-nya
